# Mindaloy

A spaced repetition web app for learners and developers, with an API so agents and other systems can manage cards and read review results.

## Status

Mindaloy is in planning. There is no application code yet. The draft plan is in [docs/plans/0001-plan-mindaloy-2026-10-21.md](docs/plans/0001-plan-mindaloy-2026-10-21.md).

## Install and run

Instructions will land here once the stack is chosen. The plan proposes TypeScript for the API and web client, with PostgreSQL for storage.
