Use case: ui-mockup. Create one polished high-fidelity raster UI comparison board for Mindaloy, a spaced repetition web app. Landscape composition with one large DESKTOP COLLECTIONS screen occupying the left 72 percent and one PHONE REVIEW screen occupying the right 28 percent. Both are flat orthographic software screens, no perspective and no hardware device frames. Make the board legible and beautifully typeset. The user rejects the prior design as insufficiently minimal and modern. Aim for an exceptionally restrained contemporary productivity tool. Radical reduction of visual chrome, crisp typography, flat solid fills, precise alignment, quiet negative space. NO visible outer screen borders, NO gradients, NO texture, NO noise, NO glow, NO shadows, NO glass, NO nested panels, NO huge rounded cards, NO colored grade button grid, NO decorative charts, NO mascots, NO marketing hero. Small 5px button corners at most. Keep screens separated by a narrow neutral gutter.

Identical product content for each variant: desktop title "Collections", small summary "24 due", single main action "Review all", secondary text action "New collection". List three collections as unboxed text rows with subtle horizontal hairlines only where necessary: "TypeScript" with "128 cards" and "12 due"; "System design" with "86 cards" and "8 due"; "Spanish" with "240 cards" and "4 due". Do not repeat Review buttons on every row. Make the collection names visibly more prominent than the counts. Include a quiet settings link "Integration settings". No dashboard stats panels.

Phone screen shows a review after key points are revealed: small top navigation "TypeScript" and "3 / 24", quiet close icon. Large readable cue "What does a closure retain?" Label "Your answer" and plain text "Access to variables from its surrounding scope." Label "Key points" and plain text "A function retains access to its lexical scope after the outer function returns." Avoid enclosing either answer in a card. At the bottom, small label "Grade your recall", four equal neutral buttons in one row with labels "Again", "Hard", "Good", "Easy", all equally emphasized and none selected. These are minimum 44px high in the implied phone layout. Show a very thin progress line. Screen content uses comfortable 20px side margins. No keyboard visible in this after-reveal state. Counts and text are placeholder content.

Typography must look like real clean software, with careful size hierarchy and consistent baseline rhythm. Main text uses high contrast; secondary text remains readable. Use the exact text above, no invented additional interface features. This is an original Mindaloy concept, not a reproduction of another company's UI.
