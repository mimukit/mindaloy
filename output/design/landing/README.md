# Mindaloy landing page concepts

[Issue #10](https://github.com/mimukit/mindaloy/issues/10) tracks the landing page implementation and embeds the selected light and dark mockups.

The selected variation 2 has a [polished light version](02-quiet-instrument-v6.png) and a [dark version](02-quiet-instrument-dark-v2.png). The dark version uses the approved palette and preserves the layout and final CTA. Its [theme prompt](02-quiet-instrument-dark-v1-prompt.txt) and [label correction](02-quiet-instrument-dark-v2-prompt.txt) record the image edits.

These raster mockups include an introduction, a review section, a separate cards and collections section, and API access. Each board compares desktop and phone layouts. These are design references, not application pages.

The owner selects variation 2 for refinement. The [polished version](02-quiet-instrument-v6.png) aligns the grade controls with the fields, adjusts panel spacing, simplifies phone navigation, and adds a CTA before both footers. The [polish prompt](02-quiet-instrument-v4-prompt.txt), [spacing correction](02-quiet-instrument-v5-prompt.txt), and [text correction](02-quiet-instrument-v6-prompt.txt) record the edits. The [polish review](02-polish-review.txt) records the visual checks and remaining limits. These changes do not establish measured production spacing tokens.

The five Taste directions use seed `20261022`. The [direction records](directions/) retain the palette and type. The [brief](brief-v2.txt) records the claims, sample content, and changes to the generic blueprints. The [image review](image-review.txt) records the remaining problems.

The built-in image tool creates every mockup. No external photographs or clips appear. The existing application mockups supply the product references. Generated lettering and shading still require correction during implementation. No browser, contrast, font-loading, keyboard, responsive, or motion checks run on these static images.

Each image has a matching prompt file. The final original also uses [its first prompt](00-improved-prompt.txt), [the API correction](00-improved-v2-prompt.txt), and [the footer correction](00-improved-v3-prompt.txt). Variation 2 also uses [its composition correction](02-quiet-instrument-v2-prompt.txt) and [its final correction](02-quiet-instrument-v3-prompt.txt).

The earlier `landing-light-v1.png` remains unchanged. Numbered intermediate images remain available as draft records. No landing page code is added.
